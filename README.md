# Trigenys Commerce Factory

Web application generated by Trigenys AppFactory.

## Baseline

- React 19
- TypeScript
- Vite
- Node.js 24 CI
- AppFactory Project Automation through the zero-PAT OIDC broker
- versioned AppFactory webapp marker

## Development

```bash
npm install
npm run dev
```

Validate with:

```bash
npm run typecheck
npm run build
```

## Architecture boundary

This preset intentionally provides a small frontend foundation rather than guessing product architecture.

The generated repository owns product-specific routing, state, API boundaries, authentication, observability, persistence and deployment choices. Add those only when the product requirements justify them.

## AppFactory

Preset: `react-vite`  
Blueprint version: `1`
