Status: active prospecting research  
Related: #2, #43, #44

## Purpose

Select three public, WhatsApp-first merchants for personalized Commerce Factory demonstrations before outreach.

These are **unofficial private demos**. Public merchant information may be used to illustrate the product, but Commerce Factory must not imply endorsement, partnership or ownership of the merchant brand. Demos stay non-indexed until the merchant opts in.

## Demo rules

For all three:
1. use only public business/catalog information;
2. never invent prices, stock, claims or reviews;
3. label every page **Unofficial Commerce Factory demo — not the merchant's official site**;
4. add `noindex, nofollow`;
5. do not expose the demo in public navigation or sitemap;
6. use the merchant's public WhatsApp number only for a handoff the merchant can inspect;
7. do not send automated messages or place test orders;
8. remove or convert the demo immediately if the merchant asks.

## Outreach sequence

1. Build the demo.
2. Capture one desktop and one mobile proof image.
3. Send a permission-first message without the link.
4. If the merchant agrees, send the demo.
5. Run the #2 discovery + guided test.
6. Ask whether they will pilot with real products.
7. Record fit, objections and willingness-to-pay evidence.

## Funnel target

3 personalized demos → 3 permissions requested → 2+ demos viewed → 1+ pilot from this first batch.

A second batch is added only after the first three teach us what to change.
