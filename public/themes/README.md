# Fictional storefront sample imagery

These assets illustrate the public theme showroom and picker. They are AI-generated fictional products, never merchant uploads, inventory or brand endorsements. No merchant record is modified to use them. Existing landing assets are kept separately.

Created with the built-in image generation tool. WebP delivery files are downscaled to 480 and 960 pixels; alpha is preserved for cutouts. Source PNGs remain generation originals. Each key has sibling `-v1-480.webp` and `-v1-960.webp` files.
